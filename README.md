# 考试大师 · 网页前端原型

面向学生的考试学习平台交互原型，使用原生 HTML、CSS 和 JavaScript。可体验登录、课程浏览与激活、学习规划、在线答疑，以及个人学习档案等页面。

## 本地体验

下载或克隆本仓库后，用浏览器打开 `index.html`，无需安装依赖或启动后端。

- 每次打开或刷新都先显示登录页。可点击「3 秒快捷登录」，或输入符合格式的演示手机号、勾选协议并输入验证码 `1234`。
- 课程激活使用演示码 `JQ2026`。
- 学习档案和演示状态保存在当前浏览器的本地存储中。

登录、课程激活和答疑均为前端演示，不会发送真实短信，也不连接真实账号或 AI 服务。请使用占位信息体验。

## 文件

- `index.html`：浏览器入口和页面外壳。
- `styles.css`：登录页、导航、课程卡片等样式。
- `app.js`：页面渲染、演示交互和本地状态。
- `*.webp`、`*.png`：登录背景与课程配图。
